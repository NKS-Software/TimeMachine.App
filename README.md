# TimeMachine.App

Консольное приложение для демонстрации возможностей [TimeMachine.Core](https://github.com/NKS-Software/TimeMachine.Core).

## Что делает

- Позволяет «перемещаться» во времени через интерактивное меню (`Screens.cs`).
- Показывает, как `SharedTimeProvider` влияет на работу приложения.
- Демонстрирует использование констант форматов дат из `TimeMachine.Core`.

## Зачем

Это **песочница** для `TimeMachine.Core` — можно посмотреть, как работает подмена времени, не подключая библиотеку в реальный проект.

## Статус

Демонстрационное приложение. Используется для тестирования `TimeMachine.Core` в действии.
